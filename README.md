# Koketso's AI Assistant

Build a modern, responsive web application called Koketso's AI Research Productivity Assistant that helps professionals automate workplace tasks using AI .  The application should include: 1. Task planner/ scheduler ( Generate daily or weekly schedules, prioritize tasks effectively). 2. AI  Research Assistant ( Summarize topics/ articles, provide insights and recommendations). 3. AI Chatbot Interface ( Interactive AI workplace Assistant, Handle user prompts and responses) .  Requirements: Modern dashboard UI. Sidebar navigation. Responsive Design. Structured AI prompts. Editable AI outputs. Responsible AI disclaimer. Design style  should be clean, modern and professional similar to a SaaS platform
